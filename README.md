# huraneko homepage

フラネコの個人ホームページです。

GitHub Pages向けの公開ファイルは `docs/` に配置しています。

## 公開ページ

- トップページ: `docs/index.html`
- プライバシーポリシー: `docs/privacy-policy/index.html`
- AdMob用ファイル: `docs/app-ads.txt`

## メモ

- 派遣先の社名は掲載しません。
- 趣味で作成した別ツールは、このホームページには掲載しません。
- `app-ads.txt` の出版社IDは、AdMobの実IDに差し替えてから使います。
